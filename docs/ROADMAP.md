# mini-cesium · 零依赖功能清单(ROADMAP)

> 本文档同时是工程规格和连载索引。每个里程碑 = 一个能跑的 demo + 一次提交 + 一个 tag + 一集内容。

---

## 0. 项目定位

用纯 WebGL + 原生 JavaScript,从零实现一个能加载瓦片影像与地形、有四叉树 LOD 调度的三维地球引擎。

**零依赖的含义:** 运行时依赖为 0。源码不 import 任何第三方库,无构建步骤,每个 demo 是可直接双击打开的单 HTML 文件。开发工具(测试运行器等)不算运行时依赖。

## 0.1 「及格线」定义

**做到 M5 结束,才配得上 mini-cesium 这个名字。**

MVP 判据(一条命令可验证):打开一个 HTML,3 秒内看到贴着真实卫星影像的地球;拖到任意城市放大到第 10 级不糊、不闪白、帧率稳定;点击地面能取到正确经纬度。

低于这条线的任何"完成"都只算半成品——这条线同时是连载里"手写"人设的底线。

## 2. 分里程碑功能清单

### M0 渲染底座

| 功能 | 必要性 | 验收标准 |
|---|---|---|
| WebGL2 上下文封装(创建、DPR 自适应 resize、上下文丢失恢复) | 必须 | 窗口缩放不变形;模拟上下文丢失给出提示 |
| 数学库:Vec2/3/4、Mat3/4、Quat | 必须 | 单元测试,与手算值对比,误差 < 1e-6 |
| 着色器 Program 封装(可读的编译报错、uniform 缓存、VAO) | 必须 | 编译错误能在 console 定位到着色器行号 |
| 几何生成:椭球网格参数化(位置/法线/UV/索引) | 必须 | 渲染出一个线框球 |
| 渲染循环与绘制命令队列 | 必须 | 稳定 60fps |
| 轨道相机(拖拽旋转、滚轮缩放、惯性) | 必须 | 拖动不飘、不抖、松手有惯性 |

### M1 第一个地球

| 功能 | 必要性 | 验收标准 |
|---|---|---|
| WGS84 椭球(a/b/f,大地坐标 ↔ ECEF) | 必须 | 与公开公式数值对齐,误差 < 1e-9 |
| ECEF ↔ ENU 局部坐标系 | 必须 | 任意点的 ENU 三轴方向正确 |
| Cartographic 类型与工具函数 | 必须 | — |
| 全球影像贴图(equirectangular 单图,离线) | 必须 | 球面贴图正确,极点无明显撕裂 |
| 方向光 + 环境光 | 可选 | 昼夜明暗过渡 |

### M2 瓦片系统(本项目的灵魂)

| 功能 | 必要性 | 验收标准 |
|---|---|---|
| Web Mercator(EPSG:3857)投影/反投影 | 必须 | 经纬度 ↔ 瓦片坐标往返一致 |
| XYZ 瓦片金字塔模型 + 可配置 URL 模板 | 必须 | 换一个 XYZ 源只改一行配置 |
| 瓦片纹理加载管线(Image→Texture、CORS、失败重试) | 必须 | 断网时降级显示父级瓦片 |
| LRU 纹理缓存与显存上限 | 必须 | 显存占用封顶,超限自动释放 |
| 调度器:优先级(屏幕中心/近处优先)、并发上限 | 必须 | 放大时视野中心先清晰 |
| 每瓦片独立 mesh 与无缝拼接 | 必须 | 相邻瓦片无接缝、无黑线 |
| 屏幕拾取(射线 → 椭球 → 经纬度) | 必须 | 点击地面取到正确经纬度 |

### M3 地形

| 功能 | 必要性 | 验收标准 |
|---|---|---|
| DEM 数据解码(Terrarium PNG) | 必须 | — |
| `sampleHeight(lon, lat)` 采样 API | 必须 | 已知高程点采样误差可解释 |
| 地形网格高度位移 + 法线计算 | 必须 | 山体受光方向正确 |
| 裙边(skirt)防裂缝 | 必须 | 相邻瓦片无裂缝 |
| 负高程(海洋/盆地)处理 | 必须 | 海平面不塌陷 |
| 高程分层着色 | 可选 | — |

### M4 LOD 调度(最难,含金量最高)

| 功能 | 必要性 | 验收标准 |
|---|---|---|
| 四叉树瓦片树 | 必须 | — |
| 屏幕空间误差(SSE)细分/合并判定 | 必须 | 放大自动细分、缩小自动回收,无卡顿 |
| 视锥剔除(手写 6 平面提取) | 必须 | 视野外瓦片不提交 draw call |
| 地平线剔除 | 必须 | 地球背面瓦片不渲染 |
| 裂缝处理 | 必须 | 相邻不同层级瓦片无闪缝 |
| 父级兜底(加载中显示父级) | 必须 | 放大全程无白块、无闪烁 |

### M5 精度与手感

| 功能 | 必要性 | 验收标准 |
|---|---|---|
| 近远裁剪面策略 + 对数深度 | 必须 | 贴地看远处无 Z-fighting、无顶点抖动 |

| Entity 点击/悬浮事件 | 必须 | 点击弹出信息 |
| 图层管理与底图切换 | 必须 | 影像源运行时切换 |
| Polyline 贴地 | 可选 | — |
| GeoJSON 读取 | 可选 | — |

### M7 性能与工程

| 功能 | 必要性 | 验收标准 |
|---|---|---|
| 统计面板(FPS / draw call / 瓦片数 / 纹理显存) | 必须 | 直播和视频里这是最好的道具 |

## 3. 明确不做(第一版 Non-goals)

写进 README,防止 scope 失控。每一条都是"想到就停"的红线:

- 3D Tiles / b3dm / glTF 模型加载
- 矢量瓦片(MVT)
- 后处理、粒子、体积云、天气效果
- WebGPU、多线程渲染器
- 时间轴、日照、阴影分析
- 兼容 Cesium API(不追求 drop-in 替换)

## 4. 工程约定

- 原生 ES Module + JSDoc 类型注释,不引入 TypeScript 编译步骤(保持"无构建"卖点)。
- 数学库必须有单元测试——它是后面一切的地基。
- 每个里程碑打 tag(`v0.1-m0` …),tag 描述里写对应的视频/demo 链接,**仓库本身就是连载索引**。
- demo 目录命名:`demo/m1-globe.html`。
